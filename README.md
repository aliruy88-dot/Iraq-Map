# Iraq Map — خرائط العراق

تطبيق خرائط وملاحة عربي (RTL أولاً) للعراق، مبني على **React + TypeScript + Vite + Leaflet** وبينات **OpenStreetMap**. الواجهة مقتبسة من `design/reference-explore.html` (مرجع بصري مستقل محفوظ كما هو) وأعيد بناؤها بمكوّنات تفاعلية حقيقية؛ خلفية SVG في المرجع ليست خريطة.

> ملاحظة صراحة: لا يعرض التطبيق أماكن أو مسافات أو طرقاً حقيقية إلّا عندما تأتي من مصادرها الفعلية. عند غياب مصدر أو مفتاح يُظهر حالة واضحة ولا يختلق بيانات.

## الميزات

- خريطة تفاعلية (Leaflet) مع تكبير/تحريك، وطبقات حقيقية بلا مفاتيح: الشوارع OSM، الخريطة الإنسانية، والتضاريس.
- تحديد الموقع عبر Geolocation فقط عند طلب المستخدم، مع معالجة الرفض والفشل برسائل واضحة، وإظهار المدينة/المحافظة من الترميز الجغرافي العكسي عند توفرها.
- بحث عن أماكن وعناوين (Nominatim) بنتائج حية واقتراحات، مع دعم العربية والإنجليزية وحالات تحميل/فارغ/خطأ.
- تصنيفات الأماكن القريبة (المقاهي، المطاعم، المساجد، الوقود، الصيدليات...) عبر Overpass API من بيانات OSM حقيقية.
- بطاقة تفاصيل المكان تعرض المعلومات المتوفرة فعلياً (العنوان، التصنيف، ساعات العمل الخام، الهاتف، الموقع) مع حساب المسافة من موقع المستخدم.
- مسارات بين نقطتين: سيارة عبر OSRM (مسار ومدة حقيقيان)، والمشي تقدير محلي صريح (وسم «تقديري») ما لم يُعدّ خادم يدعم ملف المشي.
- حفظ الأماكن محلياً (localStorage) ومشاركة رابط OSM عبر Web Share أو الحافظة.
- بوصلة حسب حساسات الجهاز (تُعطَّل بصدق إن لم تكن مدعومة)، وزر مرور مباشر معطّل مع سبب واضح (يحتاج مفتاح مزوّد).
- واجهة عربية RTL متجاوبة للهاتف والشاشات الأكبر، وخط IBM Plex Sans Arabic وأيقونات Material Symbols.
- إعدادات: اللغة (عربية/إنجليزية)، وسيلة التنقل الافتراضية، حالة مصادر البيانات، إعادة تعيين البيانات المحلية.

## المتطلبات

- Node.js ≥ 20 (طُوِّر مع Node 22) و npm.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # اختياري — القيم الافتراضية تعمل بلا مفاتيح
npm run dev                  # ثم افتح http://localhost:5173
```

البناء والاختبار:

```bash
npm run build      # tsc + vite build (الناتج في dist/)
npm run preview    # تفحص البناء
npm test           # vitest (وحدات + حالات فشل)
npm run lint       # oxlint
npm run typecheck  # tsc -b
```

## المتغيرات البيئية (انظر `.env.example`)

لا تضع أي مفتاح في الشيفرة ولا ترفع `.env.local` إلى Git.

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `VITE_APP_NAME` | Iraq Map | اسم التطبيق |
| `VITE_TILE_URL` | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | رابط بلاطات الخريطة (يدعم `{key}`) |
| `VITE_TILE_API_KEY` | فارغ | مفتاح طبقة إذا كان المزوّد يتطلبه |
| `VITE_GEOCODER` | `nominatim` | `nominatim` أو `photon` |
| `VITE_NOMINATIM_URL` | `https://nominatim.openstreetmap.org` | بحث/ترميز جغرافي |
| `VITE_OVERPASS_URL` | `https://overpass-api.de/api/interpreter` | تصنيفات الأماكن القريبة |
| `VITE_OSRM_URL` | `https://router.project-osrm.org` | المسارات (سيارة) |
| `VITE_OSRM_WALK_PROFILE` | فارغ | ضع `foot` فقط إذا كان خادمك يدعم المشي فعلاً وإلا يبقى المشي تقديرياً |
| `VITE_DEFAULT_LOCALE` | `ar` | اللغة الافتراضية |
| `VITE_ENABLE_DEMO_DATA` | `false` | بيانات توضيحية موسومة عند غياب الاتصال |

### المسارات

- المسار بالسيارة يأتي من OSRM (ملف `driving`) ببيانات فعلية.
- المشي تقدير محلي (مسافة مباشرة ÷ سرعة مشي) موسوم «تقديري»؛ الخادم العام `router.project-osrm.org` لا يوفّر ملف مشي واقعياً. لمن يريد مسار مشي حقيقياً: شغّل خادم OSRM بملف `foot` وضع `VITE_OSRM_WALK_PROFILE=foot`.

## حدود صادقة

- الخدمات العامة (OSM tiles، Nominatim، Overpass، OSRM) مفتوحة لكن **للاستخدام الخفيف** ولها سياسات استخدام؛ للاستخدام الإنتاجي مهِّئ عناوينك/مفاتيحك في `.env.local`.
- عند انقطاع الاتصال تُعرض رسائل واضحة، وأزرار المرور المباشر والبوصلة لا تدّعي حالة مزيفة.
- البيانات التجريبية (إن فُعّلت) موسومة بوسم «بيانات تجريبية» ولا تمثّل أماكن حقيقية.

## البنية

```
src/
  config/        قراءة متغيرات البيئة وحالات المزوّدين
  services/      http + geocoding + overpass + routing + location + storage + demo
  hooks/         geolocation، search، categories، route، compass، online
  state/         إعدادات/i18n والمفضلة (سياقات)
  components/    header، search، chips، map (MapCanvas + controls)، place card، nav
  screens/       استكشاف، مسارات، محفوظات، إعدادات
  i18n/          نصوص عربية/إنجليزية
  utils/         مسافات، تنسيق، تسميات OSM، أيقونات
design/          مرجع الواجهة الأصلي (محفوظ كما هو)
```
