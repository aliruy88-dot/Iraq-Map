# سجل التقدم — Iraq Map

## بيئة التنفيذ
- Flutter/Dart غير متوفرة في البيئة؛ Node 22 + npm متوفرة، والمتصفحات غير مثبتة محلياً (تحقق تلقائي عبر فحوص البناء/الاختبار وسيرفر dev).
- القرار: **ويب حديث (React 19 + TypeScript + Vite 8 + Leaflet)** — أبسط خيار مناسب، والمرجع البصري نفسه واجهة ويب.
- مصادر بيانات حقيقية متاحة عبر الشبكة وبدون مفاتيح: OSM tiles، Nominatim، Overpass، OSRM (كلها أُختبِرت يدوياً عبر curl قبل الاستخدام).

## ملاحظات تصميم قرار
- البحث مقيّد بالعراق (`countrycodes=iq`)؛ المصادر والمسافات تُعرض فقط من بيانات حقيقية أو حساب فعلي.
- المشي تقدير صريح «تقديري» (الخادم العام لا يوفر ملف foot)؛ قابلة للتفعيل عبر `VITE_OSRM_WALK_PROFILE=foot`.
- المرور المباشر معطّل بصدق (يتطلب مفتاح مزوّد)؛ البوصلة تعمل على أجهزة ذات حساس اتجاه.
